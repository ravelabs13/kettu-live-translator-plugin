Built for conversations — not the message feed.

Kettu Translate translates the messages you write while chatting. It does not automatically translate posts, server history or messages written by other users.

Translate without leaving Discord.

The translator lives directly in the composer, so multilingual conversations stay fast and natural.

Automatic detection

33 languages

Per-channel targets

Auto Translate

Translate when pressing Send, with independent ON/OFF overrides for individual channels.

Discord syntax protection

Mentions, URLs, custom emoji, timestamps and code are protected during translation.

Installation

Kettu Translate was developed and tested on iOS with the official Kettu project.

Open Discord and go to Settings → Kettu → Plugins.
Tap the + button.
Paste the Kettu Translate plugin URL below.
Install and enable the plugin.
Fully restart Discord.
Open a text channel. AUTO→EN should appear automatically.

Privacy

Translation requires an internet connection. Text selected for translation is sent to the Google Translate web translation endpoint used by the plugin. Kettu Translate does not operate its own translation server.

Kettu Translate tłumaczy wiadomości, które piszesz podczas rozmowy. Nie tłumaczy automatycznie postów, historii serwera ani wiadomości innych użytkowników.
