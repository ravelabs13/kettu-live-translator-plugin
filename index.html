Polish Outgoing Translator

Plugin for KettuTweak/Bunny on iOS that translates outgoing Polish Discord messages before sending.

Current version: 1.1.0

Instalacja

  1. Skopiuj poniższy adres.
  2. W Discordzie otwórz Ustawienia → Kettu → Plugins → +.
  3. Wklej adres, zainstaluj plugin i włącz go.
  4. Uruchom Discord ponownie. Pływający przycisk PL→EN pojawi się nad polem wiadomości.
  5. Dotknij pustego przycisku, aby zmienić język. Wpisz tekst i dotknij go ponownie, aby przetłumaczyć.

Installation

  1. Copy the URL below.
  2. In Discord open Settings → Kettu → Plugins → +.
  3. Paste the URL, install the plugin, and enable it.
  4. Restart Discord. The floating PL→EN button appears above the message field.
  5. Tap the empty button to change language. Type text and tap it again to translate.
